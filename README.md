# ░▒▓ - NeuroPuentes - ▓▒░

Aplicación web multiplataforma que se enfoca en crear situaciones problema para que estudiantes de psicología, enfermería y otras ramas de la salud puedan pulir sus habilidades comunicativas a la hora de entrevistar y conocer a padres de niños que se encuentran dentro del espectro autista.  

## ※Datos técnicos para los desarrolladores

### ❖ Requerimientos
* Angular 19 + WebRTC/Web Audio API para grabar voz.  
* Backend: .NET 8 + SignalR (manejo de tiempo real) + integración con Python para IA.  
* IA: Whisper (STT) + LlaMA 3/Mistral (chat) + Coqui TTS (voz).  
* Infraestructura: Servidor propio con GPU o Google Colab Pro.
